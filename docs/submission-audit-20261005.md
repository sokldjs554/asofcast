# 데이터플로 지원 프로젝트 최종 감사 — 2026-10-05

## 채용 관점의 판단

AsOfCast는 **모델 학습·평가를 검증 가능한 API와 공개 서비스까지 연결하는 지원 프로젝트**다. 회사의 [Model Craft](https://data-flow.co.kr/verta/model-craft)가 설명하는 시계열 학습, 모델 비교, API 배포 흐름과 연결된다. 회사의 실제 내부 채용 판단이 아니라 공개 제품·공고를 읽고 내린 해석이다. [공고 17개 항목별 코드·실행 근거](dataflow-role-evidence.md)를 함께 제공한다.

Python/PyTorch, 시간순 전처리, 강한 기준 모델 비교, FastAPI, ONNX Runtime, MLflow/DVC, PySpark/Parquet, Docker/Render, GitHub Actions, DLinear 공식 구현 대조를 실제 실행 경로로 제시한다. TensorFlow는 PyTorch와 대안 관계인 우대 항목이며 사용했다고 주장하지 않는다. 회사 제품을 직접 통합하거나 실제 고객 설비를 운영한 프로젝트도 아니다.

면접에서 확인할 핵심은 시간 누출 방지 설계, 모델과 배포 파일의 연결, 개선 후보의 채택 기준, 측정한 최적화 범위다. 새로운 학습 정책의 일반적인 우위는 확보하지 못했다. 이 한계를 숨기지 않고 서비스 개발·검증 역량을 중심으로 제출한다.

## 감사에서 수정한 결함

| 재현한 문제 | 보완 | 검증 |
|---|---|---|
| 같은 데이터·설정 ID에서 다른 가중치의 ONNX runtime을 연결할 수 있음 | 검증한 모델·정규화·보고서 파일 해시를 포함하는 번들 identity 결합 | 다른 가중치 조합의 runtime 로드와 승격 거절 |
| 매우 큰 timestamp·측정값이 서버 오류를 유발 | 정확히 표현 가능한 시간 범위와 수치 연산 오류 검증 | API 422 회귀 검사 |
| JSON `1e999`, `NaN`, `Infinity`의 오류 응답 직렬화가 실패 | 원본 비유한 값을 오류 JSON에 되돌려 넣지 않음 | 네 입력 모두 500 대신 422 |
| 쉼표가 들어간 센서 이름을 취득 후 분리해 해석 | 반복 query parameter로 이름 전체 전달 | 취득·대기 상태 보존 |
| 재방문 브라우저에 새 설명과 예전 연구 표가 함께 표시 | 연구 JSON 버전 URL·캐시 비사용·기대 날짜 검증 | 실제 공개 브라우저에서 재현, Node 실행 회귀 및 브라우저 회귀 추가 |

모델 학습·전처리·시간축·정책·평가·번들·서빙·승격·UI·CLI·MLOps·Spark·벤치마크·재현 스크립트와 CI 설정을 검토했다. 모든 과거 실험 전체를 다시 학습하거나 상용 부하·보안 감사를 수행했다는 뜻은 아니다.
