독립 리뷰에서 발견한 ‘더 이상 대기·취득할 수 없는 상태’의 재시도 안내와 모션 감소 설정 적용을 수정했다. 리뷰어 환경의 Chromium 실행은 소켓 권한 오류로 막혔으므로 그 시도는 통과 검사에 포함하지 않았다. 실제 localhost HTTP 촬영 경로와 데스크톱·모바일 화면도 확인했으며 공개 촬영 근거는 다음 절에 별도로 기록한다.

## 설치 오류 수정

Render의 두 빌드는 `python-dateutil` 패키지 목록 조회가 반복해서 시간 초과되어 실패했다. pip가 pandas의 이전 버전들을 역추적한 뒤 설치를 끝내지 못했다. main CI의 Python 3.11 설치에서도 같은 오류가 한 차례 있었고 재시도에서는 통과했다.

[PR #17](https://github.com/sokldjs554/asofcast/pull/17)은 이미 검증한 `python-dateutil==2.9.0.post0`의 공식 PyPI 범용 wheel을 URL과 SHA256으로 고정한다. 패키지 버전과 모델·API·UI 동작은 변경하지 않는다. 문제가 난 패키지 목록을 조회하지 않는 신규 설치(`--no-index --no-deps --target`)에 성공했고 별도 패키징 리뷰에서 차단 사항이 없었다. 새 PR의 Python 3.11·3.13 환경에서도 각각 단위·통합 140개가 통과했다. [설치 수정 PR CI 36453629188](https://github.com/sokldjs554/asofcast/actions/runs/36453629188)의 7개 작업이 모두 성공했다. 병합 커밋은 `70d70c25c8fcb39adb5548802bf6befb8e7877b8`이다.

## 재현 명령

검증한 모델 번들이 있는 환경에서:

```bash
python -m pytest -q
python scripts/check_browser.py --artifacts artifacts/demo --repeats 3 --out artifacts/browser-audit
python scripts/capture_live_demo.py --url https://asofcast.onrender.com --out docs/assets/live-m2
```

캡처에는 Chromium과 한글 글꼴이 필요하다. [캡처 워크플로](../.github/workflows/capture-demo.yml)는 해당 환경을 준비하고 WebM을 MP4/GIF로 변환한다. 첫 화면 준비 이전 구간만 제외하고 녹화의 원래 시간 흐름을 유지한다.

## 남아 있는 한계

이번 변경은 전달력·비교 결과 해석·증빙의 보완이며 모델 정확도 개선이 아니다. 실제 면접관 대상 사용성 실험은 수행하지 않았다. ETTh1에서의 예측기 개선은 ETTh2에서 재현되지 않았고 센서 취득 후보도 채택 기준을 통과하지 못했다. **모델의 일반적인 성능 우위는 여전히 입증되지 않았다.** [18개 설정의 성능 검증](model-evidence-20260928.md)을 별도로 확인할 수 있다.

공개 체험은 합성 데이터이며 실제 장비 제어, 영구 사용자 기록, 인증, 다중 사용자 부하 및 운영 SLA를 검증한 서비스가 아니다. 이전 비교 기능·촬영 개선은 [PR #13](https://github.com/sokldjs554/asofcast/pull/13)·[PR #14](https://github.com/sokldjs554/asofcast/pull/14), 실험 정정은 [검증 수정 기록](verification-repair.md)에 남아 있다.
