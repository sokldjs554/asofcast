# 현재 관측 기반 행동 가치 학습: 독립 평가 결과

비용과 대기를 포함한 일반적 성능 우위는 입증하지 못했다. 새 자료 두 개의 모든 시드에서 검증 구간은 강한 단순 전략을 유지했다. 따라서 학습 후보를 서비스에 승격하지 않는다.

## 방법

현재 causal snapshot과 현재 예측으로부터 실제 절대 오차 감소에서 추가 취득 비용과 대기 손실을 뺀 조건부 값을 학습했다. 각 계획은 추가 센서 최대 두 개와 종료 시점을 포함하며, 행동 하나를 실행한 뒤 다시 계획한다. 전체 rollout의 취득 횟수를 두 개로 제한하는 방식은 아니다. 미래 측정값과 최종 정답은 학습용 label 생성에서만 사용한다. 자연 도착한 센서는 비용을 지불하지 않는다.

Taylor/MSFT는 이미 노출된 개발 자료로만 사용했다. 검증 구간에서 5개 회귀 후보와 4개 margin을 비교해 HistGradientBoosting(15 leaves,80 iterations)을 고정했다. Taylor 개발 검증은 비용 포함 손실4.36%, MAE3.56% 개선했지만, MSFT에서는 개선이 없었다. 이 결과는 독립 우위의 근거로 사용하지 않는다.

## 독립 평가

공식 UCI BikeSharing hour.csv 17,379행과 BeijingPM25 43,824행 중 선택 열이 완전한 41,757행을 사전에 고정했다. 대체 정답을 채우지 않았으며 모든 해당 행을 사용했다. 각 자료를 따로 학습했고, 실제 날짜 대응표를 보존했다. 계산 시간축은 보존된 관측의 순서로 변환했으므로 horizon은 관측6개이며 물리적6시간을 주장하지 않는다. 모든 도착 시각과 센서 비용은 모의 값이다.

55/20/10/15 시간순 분할, lookback48,horizon6,stride4, seed42/43/44, 기존 세 도착 조건을 유지했다. 예측기와 단순 비교군의 기존 전체 후보군을 유지했다. 독립성은 새 자료의 이전에 사용하지 않은 test 구간에 대한 것이며, 반복 재학습은 새 통계 표본이 아니다.

| 자료·조건 | 강제 학습 후보의 손실 개선율 | 95% CI (표준화 손실 차이) | 채택 전략의 개선율 | 채택 기준 |
|---|---:|---:|---:|---|
| BeijingPM25/mixed_2811 | -0.566% | [-0.005158, +0.000837] | 0.000% | 미통과 |
| BeijingPM25/mixed_3811 | -0.626% | [-0.005272, +0.000761] | 0.000% | 미통과 |
| BeijingPM25/outage_2811 | -3.095% | [-0.016054, -0.007067] | 0.000% | 미통과 |
| BikeSharing/mixed_2811 | -0.236% | [-0.005643, +0.002858] | 0.000% | 미통과 |
| BikeSharing/mixed_3811 | -0.512% | [-0.009754, +0.004194] | 0.000% | 미통과 |
| BikeSharing/outage_2811 | -1.412% | [-0.016344, -0.001156] | 0.000% | 미통과 |

개선율이 음수이면 강한 단순 전략보다 비용 포함 손실이 악화한 것이다. 학습 후보는 오차를 줄인 경우에도 대기와 취득 비용 증가를 상쇄하지 못했다. outage에서 악화가 특히 컸다. 강제 후보의 모든 결과와 후퇴 선택을 함께 보존했다.

## 판단 기준

각 사전 지정 조건에서 legacy_joint와 validation_simple 모두에 대해 평균 손실1% 이상 개선, paired block95% CI 하한>0, 세 시드 모두 양의 개선, 시드별 원단위 MAE 악화≤1%를 동시에 요구했다. MAE는 두 비교군 모두와 비교했다. 세 시드의 동일 origin을 먼저 평균하고 block42로 bootstrap2000회(기존 seed)를 수행했으며 block6 민감도 분석도 보존했다. 전체6개 조건이 모두 통과해야 승격한다. 결과를 본 후 기준을 낮추지 않았다.

## 재현과 검증

수정된 연구 흐름과 관련 회귀 테스트73개가 통과했으며 새 Python 파일3개의 Ruff 및 구문 검증도 통과했다. 전체 프로젝트 검증은 별도 PR의 GitHub Actions 결과를 따른다.

기본 모델12회 독립 학습(자료2×시드3×반복2), 정책 학습 및 평가를 두 번 실행했다. 평가 배열792개가 정확히 일치했다. 선택 정책을 다시 읽어 예측/행동/비용/대기/취득 수180개 배열을 정확히 재현했다. 실제 학습 모델을 대상으로36개의 origin별 미래 값 변경 검증도 통과했다.

저장된 파일3개가 불완전한 상태임을 추가 검증에서 발견했다. 정책 및 학습 배열 한 쌍은 해당 실행에서 독립 학습한 기본 모델과 원래 설정으로 재구성했으며, 원래 검증 선택과 상대 실행의 학습 배열까지 정확히 일치했다. 재구성 후 원래 test 결과도 정확히 재현했다. 기본 bundle의 replay 하나는 원래 manifest에 기록된 SHA256와 완전히 동일한 검증된 복사본으로 복원했고 독립 학습 weights는 유지했다. 이는 추가 통계 근거로 계산하지 않는다. 복원 내역, 실패 원본 해시와 전체 파일 검사를 보존했다.

후속 재현 코드에서는 기본 학습 config와 정확한 Torch 버전도 고정하고, 기존 실행을 재사용하기 전에 source/config/checksum을 검증한다. 선택한 margin을 적용한 후 정책을 저장한다. 파일은 임시 경로에 쓴 뒤 다시 읽어 검증하고 원자적으로 교체한다. 학습 수식·후보·선택·평가 기준에는 변화가 없다. 원래 평가에 사용한 frozen source도 보존했다.

새 기본 모델로 승격하지 않는다. 제출 자료에는 인과적 시점 재현, 재현 가능한 비용 포함 비교, 실패를 숨기지 않는 평가 절차를 강점으로 기재할 수 있지만, 학습 정책의 일반적 우위 또는 실제 운영 비용 절감은 기재하지 않는다. 다음 모델 연구는 관측별 행동 가치의 불확실성과 비용을 함께 교정하는 단계이며, 현재 test는 이미 노출됐으므로 후속 튜닝 결과를 다시 독립 평가로 부르면 안 된다.
