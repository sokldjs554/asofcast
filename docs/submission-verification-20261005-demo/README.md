# 데모와 제출 자료 최종 보완 검토 2026년 10월 5일

면접관이 문제, 데이터플로 지원 목적, 구현 근거와 연구 판정을 같은 체험에서 확인하도록 보완했다. 제공받은 공고의 요구를 기준으로 평가하며 회사의 실제 센서 시스템이나 운영 비용을 검증했다고 표현하지 않는다.

## 보완한 내용

- 첫 화면에 데이터플로 AI 모델 개발자 지원 프로젝트임을 명시했다. 세 선택의 비교, 추천 실행, 사후 평가 순서는 유지했다.
- 모델 개발, 최적화, MLOps, 데이터 처리, 논문 대조, 클라우드의 여섯 카드에서 저장소 근거를 바로 연다. [공고 대응 문서](../dataflow-role-evidence.md)는 주요업무 5개, 자격요건 7개, 우대사항 5개를 구분한다.
- 최신 보존 연구의 Taylor·MSFT 여섯 조건을 모두 표시한다. 평균이 양수여도 채택 기준 미달이면 미달로 표시하며, **1/6 조건 통과·전체 실패·승격 거절**을 유지한다.
- 예측기 MAE 개선과 비용 포함 행동 정책의 개선을 구분했다. 현재 API의 추론 backend와 별도 ONNX CPU 벤치마크도 구분했다.
- 보존 ZIP과 일치하는 집계의 고정 SHA-256, 평가 파일의 해시, 기존 수치 gate 및 승격 판정을 확인해 화면용 JSON을 생성한다. 변조된 수치, 누락, 비유한 값, 모순 또는 오래된 생성 파일은 거절한다.
- 연구 집계 로딩이 실패해도 모델 체험을 사용할 수 있다. 다시 읽으면 정상 표가 복구된다. 연구로 이동해도 예측 목표, 체험 기록, 사후 정답 선택은 유지된다.

## 공고 적합성 판단

공고의 모델 설계·학습, 전처리, 성능 평가·개선, 서비스 최적화, 실험 문서화 업무가 하나의 재현 가능한 프로젝트로 연결된다. PyTorch, MLflow/DVC, Render/Docker, Spark 및 DLinear 대조에도 실행 근거가 있다. 기술 이름의 나열보다 판단 시점의 정보 누출 방지, 공정한 추론 비교, 실패 후보의 승격 거절에서 개발 판단을 설명할 수 있다.

제출 목적에 부합한다는 판단은 이 근거에 한정한다. 실제 산업 센서 도착 로그·비용 절감, 상용 SLA, 다중 노드 Spark, AWS/GCP/Azure 운영, 다인 팀 협업 및 원 논문 전체 벤치마크는 증명하지 않는다. 새 행동 정책의 일반적인 성능 우위도 미달성이다. 지원자의 개인 경력·학력은 이력서 사실로 확인해야 하며 프로젝트가 대신 증명하지 않는다.
