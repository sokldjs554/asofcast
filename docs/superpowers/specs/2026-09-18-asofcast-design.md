# AsOfCast — 승인된 설계

사용자가 2026-09-18 대화에서 승인한 새 프로젝트. 기존 저장소를 변경하지 않는다.

## 목적
데이터 수집 지연이 있을 때 고정된 미래 시점의 값을 예측하고, 마감시간 안에서
예측을 확정할 시점을 학습한다. 센서 값은 공개 실측 ETT, 수집 지연은 합성이다.
현재 구현 대상은 한 설비의 다변량 예측이며 실제 공장 운영 실증이 아니다.

## 불변 조건
- 예측 기준 시각 origin은 기다려도 바뀌지 않는다. target = origin + horizon.
- 입력 측정 시각 <= origin, 수집 시각 <= decision_time. 미래 행을 입력에 사용하지 않는다.
- 전체 시뮬레이션에서 관측 하나의 수집 시각은 고정된다. 요청마다 다시 추첨하지 않는다.
- 전처리는 학습 종료 시각까지 도착한 학습 관측으로만 적합한다.
- 예측기 학습 / 대기정책 학습 / 검증 / 테스트를 시간 순서로 분리한다.
- 분할 경계에 history+horizon 간격을 두고 서로 다른 분할의 입력/정답 구간을 겹치지 않는다.
- 정책은 현 시점 상태만 입력한다. 정답, 실제 미래 도착 시각, 미래 예측은 입력 금지다.
- 지연/정확도 동시 비교. 단순 고정대기와 같은 평균 대기의 무작위 정책도 비교한다.
- 새로운 Git 저장소를 사용한다. README에 MIT 라이선스/배지를 넣지 않는다.
- 유료 GPU/클라우드 생성, 결제수단 등록, 기존 서비스 변경은 하지 않는다.
- 로컬 실행, GitHub 게시, 클라우드 배포, 논문 수치 재현은 서로 다른 완료 항목이다.

## 첫 실행 단위
48시간 입력, 6시간 뒤 OT 한 점 예측, 대기 0/30/60분.
DLinear 방식의 분해-선형 기준 모델과 값/관측 마스크/데이터 나이/known 상태를 사용하는
작은 PyTorch 모델을 비교한다. 정책은 다음 의사결정 시점까지 기다렸을 때의 오차 감소를
정답으로 학습한다. 이 첫 정책은 1단계 예상 이득 정책이며 최적 순차정책이라고 주장하지 않는다.
한 시점 뒤의 이득을 얻기 위해 두 번 기다려야 하는 경우의 약점은 후속 backward-induction 실험 대상이다.

## 재현 및 운영
원본 SHA256, 전처리 통계, 학습/평가 설정, 버전, 체크포인트와 케이스별 결과를 보관한다.
API는 학습 결과를 실제 로드한다. 체크포인트 누락 시 준비 완료나 학습된 결과를 꾸며내지 않는다.
ONNX 검증은 수치 오차와 정책 행동 일치를 포함한다. 공개 배포는 별도 검증 전까지 미완료다.

## 전체 프로젝트에서 남겨 두는 후속 검증
원 논문 설정의 독립 재현, UCI 전체 대규모 처리, 추가 데이터셋, 지연분포 변화,
여러 초기화, 분포 이동·정책 성능 개선, 원격 GitHub CI와 무료 클라우드 실제 운영 확인.
