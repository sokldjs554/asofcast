# AsOfCast M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 실행 가능한 point-in-time 예측·대기정책 파이프라인과 검증 증거를 만든다.

**Architecture:** 동일 관측 로그에서 decision-time별 snapshot을 만든다. 학습 전처리 및 모델,
시간 분리된 정책 학습, 독립 테스트, 실제 체크포인트 기반 API를 연결한다.

**Tech Stack:** Python, NumPy, Pandas, PyTorch, pytest, FastAPI; ONNX Runtime/MLflow는 실행 가능한 확장.

**Spec:** docs/superpowers/specs/2026-09-18-asofcast-design.md

## Global Constraints
새 저장소, README 라이선스 배지 없음, 비용 지출 없음. 실측값과 합성 지연 명시.
학습/정책/검증/테스트 시간 분리. 원논문 재현/클라우드 검증을 로컬 실행과 혼동하지 않는다.
