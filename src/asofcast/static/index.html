개선은 어디까지 확인했나요?

AppliancesEnergy·SeoulBike에 대해 3개 학습 seed × 3개 도착 조건, 총 18개 설정을 평가했습니다. 평균 개선과 채택 기준을 구분합니다.

판정 확인 중

보존된 평가 결과를 불러오는 중입니다.

자료 / 조건강한 단순 기준 대비 손실 감소개선량 95% 구간개선 seed해당 조건

예측기 개선과 행동 정책 개선은 다릅니다. 별도 Appliances 실험에서 예측기 MAE는 약 10.83~11.15% 개선됐지만, 같은 개선 예측기를 쓰는 강한 단순 정책보다 비용 포함 손실은 0.67~0.92% 나빴습니다.

양수 평균만으로 채택하지 않습니다. 각 조건에서 두 비교 기준 모두 대비 손실 1% 이상 감소, 95% 구간 하한 양수, 3개 seed 모두 개선, seed별 MAE 악화 최대 1%를 요구합니다. 6개 조건 전부가 통과해야 전체 성공입니다.

표의 구간은 백분율이 아닌 표준화 손실 차이입니다. AppliancesEnergy는 이전 Appliances와 같은 원본의 재사용 평가입니다. SeoulBike만 처음 사용한 자료입니다. AppliancesEnergy는 단순 전략을 유지했고, SeoulBike는 추가 센서 비용을 상쇄하지 못했습니다. 반복 재학습은 재현성 확인이며 통계 표본을 늘린 것으로 세지 않았습니다. 실제 측정값을 사용했지만 도착 시각·취득 비용은 합성했습니다. 실제 설비의 비용 절감이나 일반적인 성능 우위를 입증하지 않았습니다.

센서를 읽었을 때의 예상과 실제

예상 오차 감소는 모델의 추정, 실제 오차 감소는 정답을 사용한 사후 평가입니다. 비용은 금액·장비 지연이 아닌 상대값입니다.

센서상태예상 오차 감소실제 오차 감소 · 사후상대 비용정책 점수직접 선택

오차 감소는 원본 값 단위, 정책 점수는 표준화된 이득에서 가중 비용을 뺀 값입니다. 두 수치의 단위는 다릅니다.

대기만 했을 때 · 별도 비교

각 시점에서 처음부터 기다린 경우를 계산한 비교입니다. 이번 체험에서 실행한 기록이 아닙니다.

더 읽는 비용과 예측 오차

현재 데이터의 같은 평가 구간에서, 센서를 한 번 더 읽는 정책의 비용 가중치를 바꿔 비교합니다.
