어떤 센서를 더 읽어볼까요?

예상 오차 감소는 모델의 추정입니다. 음수면 도움이 되지 않을 것으로 예상한 센서이며, 실제 결과는 다를 수 있습니다.

모델은 왜 이 행동을 골랐나요?

현재 들어온 정보로 계산한 추천입니다. 실제 미래 도착정보와 사후 정답은 입력으로 사용하지 않습니다.

모델 간 예측 차이: —. 서로 다른 모델 출력의 표준편차이며, 보정된 확률이나 신뢰구간이 아닙니다.

센서를 읽었을 때의 예상과 실제

예상 오차 감소는 모델의 추정, 실제 오차 감소는 정답을 사용한 사후 평가입니다. 비용은 금액·장비 지연이 아닌 상대값입니다.

센서상태예상 오차 감소실제 오차 감소 · 사후상대 비용정책 점수직접 선택

오차 감소는 원본 값 단위, 정책 점수는 표준화된 이득에서 가중 비용을 뺀 값입니다. 두 수치의 단위는 다릅니다.

대기만 했을 때 · 별도 비교

각 시점에서 처음부터 기다린 경우를 계산한 비교입니다. 이번 체험에서 실행한 기록이 아닙니다.

더 읽는 비용과 예측 오차

현재 데이터의 같은 평가 구간에서, 센서를 한 번 더 읽는 정책의 비용 가중치를 바꿔 비교합니다.

구현한 범위와 한계

실험용 서비스입니다. 실제 장비 제어·영구 저장·상용 운영 성능을 주장하지 않습니다.

미래 정보 누출 방지

측정 시각과 도착 시각을 분리합니다. 당시 알 수 있었던 관측만 추천에 사용합니다.

같은 예측 목표

기다리거나 센서를 읽어도 예측 목표는 고정됩니다. 추가 확인도 기준 시각의 값만 공개합니다.

측정값과 지연 구분

ETTh1 실험의 측정값은 실측입니다. 원본에 도착 시각이 없어 지연은 합성했습니다.
